## 运行

纯静态应用，无需构建：

```bash
# 直接打开
open index.html

# 或起一个本地服务
python3 -m http.server 8080
```

## 数据来源

数据提取自 Hermes Agent 本地数据（`~/.hermes`）：
`paper_trader/`（交易与净值）、`cron/`（任务定义与输出）、`scripts/`（策略脚本）、`strategy_changelog.md`（演化记录）。
